# ADD TO CATCH

A scroll-to-haul interactive website about sustainability and media innovation. Single file, no dependencies.

## Put it online with GitHub Pages
1. Create a new repository on github.com (e.g. `add-to-catch`), set to Public.
2. Click **Add file > Upload files**, drag in `index.html`, `README.md` and `.nojekyll`, then **Commit changes**.
3. Go to **Settings > Pages**. Under **Build and deployment**, set Source to **Deploy from a branch**, Branch **main**, folder **/ (root)**, then **Save**.
4. Wait about a minute. Your link will be `https://YOUR-USERNAME.github.io/add-to-catch/`.

Figures on the awareness section are global estimates from UNEP and WWF.
